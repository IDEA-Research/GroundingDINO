# HELPER_MEMORY.md

Long-term memory for mistakes Helper agents have made and how we stopped
them from happening again. Only Big guy writes here. Only write an entry
when a **real mistake** happened and a **real fix** is in place.

## Format

Each entry is:

```
### YYYY-MM-DD — short title

- mistake: what the Helper did wrong
- cause: why it happened
- fix: what changed (schema, prompt, validator, renderer, etc.)
- prevention rule: the invariant we now enforce
```
